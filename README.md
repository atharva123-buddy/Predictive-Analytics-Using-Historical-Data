# 📈 Predictive Analytics Using Historical Data

## Sales Forecasting Using Historical Data

A machine learning project that analyzes historical sales data,
identifies trends, evaluates predictive performance, and forecasts
future sales using Linear Regression.

---

## 🎯 Project Objective

The objective of this project is to build a predictive analytics
solution using historical sales data to:

- Clean and preprocess historical data
- Analyze sales trends
- Perform exploratory data analysis
- Build a regression-based predictive model
- Evaluate model performance
- Forecast future sales
- Visualize historical and predicted trends
- Provide data-driven business insights

---

## 🚀 Features

- 📊 Historical sales trend analysis
- 🔍 Exploratory Data Analysis
- 🧹 Data preprocessing
- 🤖 Linear Regression prediction
- 📈 Actual vs Predicted sales visualization
- 🔮 12-month future sales forecasting
- 📋 Forecast data table
- 📏 MAE, RMSE and R² evaluation
- 💡 Business insights
- 🌐 Interactive Streamlit dashboard

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Jupyter Notebook
